# bokunzheng.github.io

A minimal Jekyll-powered personal website scaffold (inspired by al-folio) with sections for:

- Home
- Education
- Research
- Projects
- Blog

## Run locally

1. Install Ruby and Bundler.
2. Install dependencies:

   ```bash
   bundle install
   ```

3. Start the local server:

   ```bash
   bundle exec jekyll serve
   ```

4. Open `http://127.0.0.1:4000`.
