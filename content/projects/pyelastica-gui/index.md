I built an interactive GUI for PyElastica and integrated MuJoCo for real-time visualization and environment interaction. The interface brings simulation configuration, data loading, playback, and analysis into one workflow.

The goal is to make deformable-body simulations easier to set up and inspect, reducing the friction between a numerical model and an interactive engineering tool.
